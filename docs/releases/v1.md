## Install from the release

On Linux x64, install Node.js 24 and the appropriate native CLI. Download both archives and `SHA256SUMS` from the release, then run these commands in the download directory. [Axiom v1.0.0](https://github.com/DanielssonThomas/Axiom/releases/tag/v1.0.0) · [Pinned Codex CLI](https://github.com/openai/codex/releases/tag/rust-v0.172.0-alpha.2) · [Pinned Hermes Agent](https://github.com/NousResearch/hermes-agent/releases/tag/v0.23.3)

```sh
sha256sum -c SHA256SUMS
tar -xf axiom-v1.0.0-runtime-linux-x64.tar.gz
tar -xf axiom-v1.0.0-native-linux-x64.tar.gz
AXIOM_CHECKOUT="$PWD/axiom-runtime"
AXIOM_DIST="$PWD/axiom-native"
```

The runtime archive includes the built Axiom checkout and its pinned dependencies. Keep it intact so applications can resolve the native packages and check the source revision. Native account credentials remain in the host's own credential store.

### Codex

```sh
node "$AXIOM_CHECKOUT/packages/cli/dist/index.js" codex install --distribution "$AXIOM_DIST"
codex plugin list --marketplace axiom-local --available --json
```

Approve the installed Axiom hook through Codex's native trust control before using the guarded workflows. Start a new session and verify policy and skill loading. For another destination or a pinned executable outside your path, use the installer's `--home` and `--program` options. [Native Codex installation and verification](../install.md#codex-cli)

### Hermes

```sh
AXIOM_HERMES_URL=$(node -p 'require("node:url").pathToFileURL(process.argv[1]).href' "$AXIOM_DIST/hermes")
AXIOM_HERMES_PIN=$(git -C "$AXIOM_DIST/hermes" rev-parse HEAD)
hermes profile create axiom-test --no-alias --no-credentials
hermes --profile axiom-test plugins install "$AXIOM_HERMES_URL" --ref "$AXIOM_HERMES_PIN" --no-enable
hermes --profile axiom-test plugins enable axiom
hermes --profile axiom-test plugins list --user --json
```

Use your existing named profile in place of `axiom-test` if you already configured one. Start a fresh session and verify policy and skill loading. [Native Hermes installation and verification](../install.md#hermes-agent)
